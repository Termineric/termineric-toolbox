SSH / Tunnels

Tunnel naar CaddyServer van werk

Gebruik deze tunnel als je lokaal met MariaDB/MySQL op de werkserver wilt verbinden. De lokale poort wordt 3307. De server zelf blijft intern op 127.0.0.1:3306.

Local port: 3307 Server DB: 127.0.0.1:3306 SSH user: eric Server: 93.174.111.65
SSH tunnel starten
ssh -N -L 3307:127.0.0.1:3306 eric@93.174.111.65
Database connectie lokaal
Host: 127.0.0.1
Port: 3307
User: jouw_database_user
Password: jouw_database_password

Laat dit terminalvenster open staan zolang je databaseverbinding nodig hebt. Stoppen kan met Ctrl + C.

Laravel

Storage link repareren

Gebruik dit als afbeeldingen/bestanden uit storage/app/public niet meer zichtbaar zijn na uploaden of kopiëren van nieuwe code.

Controleer of public/storage een link of map is
ls -ld public/storage
  • Goed: regel begint met l en toont public/storage -> ../storage/app/public
  • Fout: regel begint met d. Dan is het een echte map geworden.
Symlink verwijderen als het een link is
unlink public/storage
Alleen gebruiken als public/storage een echte map is
rm -rf public/storage
Storage link opnieuw maken
php artisan storage:link
Controle na herstel
ls -ld public/storage
ls storage/app/public
Rechten herstellen als bestanden niet zichtbaar/schrijfbaar zijn
sudo chown -R www-data:www-data storage bootstrap/cache
sudo chmod -R 775 storage bootstrap/cache

Builders

Onderdelen aanmaken: controllers, models, requests, middleware.

Controller maken
php artisan make:controller ProductController
Resource controller maken
php artisan make:controller ProductController --resource
API controller maken
php artisan make:controller Api/ProductController --api
Model maken
php artisan make:model Product
Model + migration maken
php artisan make:model Product -m
Model + migration + controller maken
php artisan make:model Product -mc
Model + migration + resource controller maken
php artisan make:model Product -mcr
Middleware maken
php artisan make:middleware RoleMiddleware
Form request maken
php artisan make:request StoreProductRequest
Command maken
php artisan make:command SyncProducts

Database

Database bouwen, wijzigen en vullen.

Migration maken
php artisan make:migration create_products_table
Migration uitvoeren
php artisan migrate
Laatste migration terugdraaien
php artisan migrate:rollback
Database opnieuw opbouwen
php artisan migrate:fresh
Seeder maken
php artisan make:seeder ProductSeeder
Seeders uitvoeren
php artisan db:seed
